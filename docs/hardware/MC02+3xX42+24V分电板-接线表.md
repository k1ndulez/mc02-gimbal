# MC02 + 3×X42 + 24V 分电板 · 完整接线表

> 机械臂版：1 底座旋转 + 2 关节，脉冲+方向主控，CAN 备用汇流。
> 本文所有 MC02 引脚均取自《DM-MC-Board02 使用说明书 V1.1》附录一管脚配置图与第 17 节扩展 IO 表；
> 所有 X42 端子均取自《ZDT_X42S 用户手册 V1.0.5》第 1.7 节接口说明与接线示意图。
> 机器校验：`python -X utf8 docs/hardware/check_wiring.py`（应输出 0 FAIL）。

**先说三句要命的：**

1. **三个 X42 的 `com` 只能并接 3.3V**（MC02 扩展口 #8）。禁止接 5V 或 24V —— 光耦会把 5V/24V 灌进 H723 的 `stp/dir` 引脚，MCU 当场报废。
2. **24V 只在分电板熔断**。MC02 自带防反接+缓启动，X42 自带反接保护，但三根 24V 分支线必须各自有保险丝。
3. **上电前先量 COM 对 GND = 3.3V**，再插电机。三轴不要一次全上。

## 0. 电源树（Power Tree）

```text
        24V 开关电源（建议 10A；4A 不够）
                 │  16AWG 红(+)/黑(−)
        ┌────────┴─────────┐
        │   J1 主输入 2P    │
        └────────┬─────────┘
                 │
         [F0 主保险 10A]
                 │
        [D1 防反接 P-MOS / SS54]
                 │
                 ├──────── 24V 母线（TP24）
                 │
   ┌─────────┬───┴─────┬─────────┬──────────┐
  [F1 1.5A] [F2 3A]  [F3 3A]  [F4 3A]   [F5 2A]
   │         │        │        │          │
 OUT1      OUT2     OUT3     OUT4       OUT5
 MC02     X42 base  X42 J1   X42 J2     24V 备用
  │         │        │        │       (视觉降压/夹爪)
  └ XT30    └ X42 V+/Gnd      └ …
                 │
        三轴共地 → MC02 GND（必须，信号才有参考）
```

MC02 自身还有两级板载电源（说明书第 3 页）：

| 板载电源 | 能力 | 给谁 | 使能 |
|---|---|---|---|
| DCDC 5V 可控 | 2A | 4 路 PWM 口、UART 口、CAN3 收发器 | `PC15`（5V_EN，拉高输出） |
| DCDC 5V 板内 | 0.6A | 板内系统 | 无需使能 |
| DCDC 3.3V | 1A | MCU / 扩展口 3V3 / 三轴 COM | 自动 |

> **5V 是可控的**：`PC15` 拉高才有 5V 输出（板上 5V_EN 指示灯亮）。视觉模块和 CAN3 都靠它，程序里先打开再用。

## 2. 24V 分电板接线表

### 2.1 原理（不画 PCB，只定端子）

```text
J1(+) ──[F0 10A]──[D1 防反接]──┬── TP24 ──┬── F1 ── OUT1 ── MC02
J1(−) ───────────────────────┴── TPGND ──┼── F2 ── OUT2 ── X42 base
                                          ├── F3 ── OUT3 ── X42 J1
                                          ├── F4 ── OUT4 ── X42 J2
                                          ├── F5 ── OUT5 ── 24V 备用
                                          └── CAN 汇流区（CAN_H/CAN_L/GND）
```

### 2.2 端子位置与规格表

| 位号 | 用途 | 器件/规格 | 线径 | 备注 |
|---|---|---|---|---|
| J1 | 24V 输入 | KF128-5.08 2P 或 XT60 | 16AWG | 电源正负不可反 |
| SW1 | 主开关（建议） | 船型 16A/250V | 16AWG | 装的话串在 J1 与 F0 之间 |
| F0 | 主保险 | 汽车插片 10A（慢熔） | — | 保护电源与母线 |
| D1 | 防反接 | P-MOS 理想二极管；或 SS54 肖特基 | 16AWG | SS54 压降 ~0.45V@5A |
| OUT1 | MC02 | 2P 5.08 端子 + XT30 公头 | 22AWG | 经 F1=1.5A（或 2A） |
| OUT2 | X42 base | 2P 5.08 端子 | 20AWG | F2=3A |
| OUT3 | X42 joint1 | 2P 5.08 端子 | 20AWG | F3=3A |
| OUT4 | X42 joint2 | 2P 5.08 端子 | 20AWG | F4=3A |
| OUT5 | 24V 备用 | 2P 5.08 端子 | 22AWG | F5=2A；视觉降压/夹爪 |
| TP24 / TPGND | 测试点 | 1.0mm 焊盘或排针 | — | 上电自检必测 |
| LED24 / LED1~5 | 指示灯 | 0805 或 3mm LED + 2kΩ | — | 每路一个，方便排故 |

### 2.3 保险丝选型依据

| 支路 | 额定 | 为什么 |
|---|---|---|
| F0 主 | 10A | = 电源 10A，保护电源与总线；三轴同时满载时先断，属预期 |
| F1 MC02 | 1.5A | MC02 平均 0.3A，峰值 <0.6A；1.5A 防后级短路又不误断 |
| F2~F4 X42 | 3A | X42 手册“推荐 3A 以上电源”；单轴峰值约 4A 由电源恒流与主保险兜底 |
| F5 备用 | 2A | 视觉降压/夹爪，按 24V/48W 上限留 |

> 分支保险之和（12.5A）> 主保险（10A）是**正常设计**：分支保险保护单根线束，主保险保护电源与母线，两者保护对象不同。想三轴长跑满载，把电源换 12~15A、F0 换 15A，分支不变。
>
> **待机电流别忽略**：三个 X42 上电即被内部逻辑使能（`En=Hold`），每个静态约 0.3~1A（24V），三轴待机就吃 1~3A。10A 电源够用，但**别把 4A 电源接上来**。

### 2.4 可选 CAN 汇流区

| 位号 | 用途 | 规格 |
|---|---|---|
| J2 | CAN 母线进（来自 MC02 CAN3） | 3P 5.08 端子：CAN_H / CAN_L / GND |
| J3~J5 | 三轴 X42 CAN 分支 | 3P 5.08 端子（或 XH2.54） |
| JP1 | 末端 120Ω 终端跳线 | 2.54 排针 + 120Ω 1/4W；**只能一端接通** |
| JP2 | 中间分支跳线（短接后星形更方便） | 2.54 排针 |

CAN 拓扑与终端见 §7。

## 3. X42 侧公共约定（三轴都一样）

### 3.1 端子：X42S 板边单排（说明书 1.7 节）

| X42 丝印 | 方向 | 本次接法 |
|---|---|---|
| `V+` | 电源入 | 分电板 OUT2/3/4 的 24V |
| `Gnd` | 电源地 | 分电板 OUT2/3/4 的 GND（并与 MC02 GND 共地） |
| `Com` | 光耦公共端 | **3.3V**（扩展口 #8） |
| `En` | 使能 | 与 `Com` 同点（3.3V）→ 参数设 Hold，一直使能 |
| `Stp` | 脉冲（= PUL） | MC02 PWM 排口信号脚 |
| `Dir` | 方向 | MC02 GPIO |
| `R/A/H` | 复用口 1 | CAN 备用时 = CAN_H；保留时悬空 |
| `T/B/L` | 复用口 2 | CAN 备用时 = CAN_L；保留时悬空 |

> **X42 丝印是 `Stp/En`，不是 `PUL/ENA`**：`PUL = Stp`，`ENA = En`，`DIR = Dir`。接线时按丝印找，别按驱动器通用叫法找。

### 3.2 共阳电平链路（为什么 COM 接 3.3V 是安全的）

```text
3.3V (COM) ──► [光耦 LED] ──► X42 内部电阻 ──► Stp/Dir/En 引脚 ──► MC02 GPIO
                                                       │
                                          GPIO 输出低 → 光耦导通 → 信号有效
                                          GPIO 输出高 → 光耦截止 → 信号无效
```

- X42 手册：脉冲输入 **3.3~24V 免串电阻**，光耦版**仅支持共阳**。
- 官方 STM32 例图就是 **Com→3.3V、Gnd→GND 共地、Stp→Stp、Dir→Dir**。
- MC02 的 H723 GPIO 输出高是 3.3V，与 COM 同电位 → 光耦两端无压差，可靠截止；输出低时灌电流约 4~8mA，H723 单脚可承受。
- **如果 COM 接 5V/24V**：GPIO 的 3.3V 拉不低光耦阳极电位，5V/24V 会反灌进 `stp/dir` 引脚 → 烧 MCU。这是这张表里唯一的“一错就报废”的点。

### 3.3 X42 参数（每轴都要设，屏幕菜单或上位机）

| 参数 | 值 | 说明 |
|---|---|---|
| `P_Pul` | `PUL_ENA` | 开启脉冲端口（En/Stp/Dir） |
| `P_Serial` | `UART_FUN`（默认）→ CAN 备用时改 `CAN1_MAP` | 复用口用途 |
| `En` | `Hold` | 一直使能；否则 En 接 3.3V 会变成“失能” |
| `Dir` | 按实际装配方向设 `CW/CCW` | 三轴各自标定，别抄同一个值 |
| 细分 | 16 | 1.8° 电机 → 3200 脉冲/圈 |
| `ID_Addr` | base=1 / joint1=2 / joint2=3 | CAN 备用时用 |
| 波特率 | 115200（CAN 时为 1Mbps） | |
| `Checksum` | 0x6B（默认） | |

### 3.4 三轴参数

| 轴 | 角色 | 细分 | 脉冲/圈 | 建议转速 | 步进频率上限 |
|---|---|---|---|---|---|
| M1 base | 底座回转 | 16 | 3200 | 30 rpm | 1.6 kHz |
| M2 joint1 | 大臂俯仰 | 16 | 3200 | 60 rpm | 3.2 kHz |
| M3 joint2 | 小臂俯仰 | 16 | 3200 | 60 rpm | 3.2 kHz |

### 3.5 X42 电源入口：**禁止杜邦线**（杜邦只走信号）

网上教程常拿杜邦线从 `V+`/`Gnd` 取电，是因为 X42S 的电源脚和 `En/Stp/Dir` 确实在同一排 2.54 针上。但**电源不能这么接**：

| 问题 | 数据 |
|---|---|
| 载流 | 普通 26AWG 杜邦安全载流约 0.5~1A；X42 单轴典型 1~3A、峰值 5A |
| 压降 | 26AWG 约 0.13Ω/m，2m 往返 0.27Ω → 3A 时掉 **0.8V**、线上发热 **2.4W** |
| 对比 20AWG | 约 0.033Ω/m，2m 往返 0.066Ω → 3A 时只掉 **0.2V** |
| 接触 | 杜邦簧片靠弹力，振动会松；松一半时接触电阻飙升 → 打火、X42 欠压复位、丢步 |
| 拔插 | X42 手册明确“**请勿带电拔插供电源**”，杜邦恰恰最容易带电被拽掉 |

**三种正解（按优先级）：**

1. **X42 专用 2P 电源端子**（板上绿色插座，手册图里接 DC 头那个）＋ 20AWG 线 —— 首选。
2. **XH2.54 2P**（3A 级连接器）＋ 20~22AWG 压接 —— 板上没有专用端子时用。
3. **直接焊 20AWG** 到 `V+`/`Gnd` 排针 —— 最土但最可靠，机械臂不常拆就用它。

**兜底**：非要用 2.54 排针取电，至少上 **KF128-2.54 螺钉端子**，别用杜邦插头。

**可以继续用杜邦的**：`Com`、`En`、`Stp`、`Dir`（mA 级光耦电流，压降可忽略）。**别用杜邦的**：`V+`、`Gnd`。

> 判断口诀：**杜邦走信号，端子走电流。** 一根线上超过 1A，就不该是杜邦。

## 4. 三级控制信号接线总表（MC02 → X42）

### 4.1 脉冲 / 方向 / 使能

| 轴 | X42 端子 | MC02 引出位置 | MC02 引脚 | 定时器/模式 | 线色 | 连接器 |
|---|---|---|---|---|---|---|
| **M1 base** | `Stp` | **PWM4 排口**（信号脚） | `PE13` | TIM1_CH3 | 白 | 3P XH2.54 / 杜邦 |
| | `Dir` | **LCD 口 #9** | `PD10` | GPIO 输出 | 黄 | 1P 杜邦（只取 #9） |
| | `En` | 扩展口 #8（VCC_3V3） | — | 与 Com 同点 | 紫 | |
| | `Com` | **扩展口 #8** | — | 3.3V | 紫 | |
| **M2 joint1** | `Stp` | **PWM 排口（TIM1_CH4）** | `PE8` | TIM1_CH4（与 TIM1_CH3 独立频率） | 白 | 3P XH2.54 |
| | `Dir` | **24Pin 扩展口 #13** | `PE14` | GPIO 输出 | 黄 | 1P 杜邦 |
| | `En` / `Com` | 扩展口 #8 | — | 3.3V | 紫 | |
| **M3 joint2** | `Stp` | **PWM1 排口**（信号脚） | `PA0` | TIM2_CH1 | 白 | 3P XH2.54 |
| | `Dir` | **24Pin 扩展口 #11** | `PD14` | 原 UART9_RX，配成 GPIO | 黄 | 1P 杜邦 |
| | `En` / `Com` | 扩展口 #8 | — | 3.3V | 紫 | |

> **为什么 base/joint1 用 TIM1、joint2 用 TIM2**：`PA0`(TIM2_CH1) 与 `PA2`(TIM2_CH3) 同属 TIM2，共享计数器和 ARR，只能跑同一频率；要三轴独立调速，至少需要两个定时器。`PE13`/`PE8` 在 TIM1 上，`PA0` 在 TIM2 上，正好三路独立。`PA2`、`PE9` 本次空着当备用。

### 4.2 供电与地

| 轴 | X42 端子 | 来源 | 线色/线径 | 连接器（X42 端） | 说明 |
|---|---|---|---|---|---|
| M1 | `V+` | 分电板 OUT2 | 红 20AWG | **专用 2P 电源端子**（无则 XH2.54 或焊接） | 经 F2 3A；**禁止杜邦** |
| M2 | `V+` | 分电板 OUT3 | 红 20AWG | 同上 | 经 F3 3A；**禁止杜邦** |
| M3 | `V+` | 分电板 OUT4 | 红 20AWG | 同上 | 经 F4 3A；**禁止杜邦** |
| 三轴 | `Gnd` | 分电板 OUT2/3/4 GND | 黑 20AWG | 同上 | **三轴 GND + MC02 GND 必须同一点汇合**；**禁止杜邦** |
| COM/En | `Com`/`En` | MC02 扩展口 #8 | 紫 24AWG | 杜邦/XH2.54 均可 | 三轴并接，电流合计 <20mA |

> 每个 X42 的 `V+` 与 `Gnd` 从各自的 OUT 端子**单独走线**，不要三轴串成一根再分叉——这是“一根线烧三轴”的常见原因。

## 5. 视觉模块接线（MaixCAM Pro / K230）

| 视觉模块端 | MC02 端 | 线 |
|---|---|---|
| `5V`（或 USB-C 供电） | PWM 排口 5V（可控，`PC15` 使能） | 橙 22AWG |
| `GND` | PWM 排口 GND | 黑 22AWG |
| `TX`（模块发） | **USART1 #3 RX = `PA10`** | 绿 24AWG |
| `RX`（模块收） | **USART1 #2 TX = `PA9`** | 蓝 24AWG |

- 波特率先用 115200 8N1，和视觉模块固件一致。
- **5V 只有 2A**：MaixCAM Pro 峰值约 1.5A，K230 约 1.2~1.5A，够用但**只能接一个视觉模块**。
- 视觉模块若自带 24V→5V 降压或要跑高帧率，改接分电板 **OUT5**，**绝不能**把外部 5V 与 MC02 的 5V 并接。
- 备选串口：**UART7（`PE8`/`PE7`）**，PWM 排口的 `PE08` 本次空着，正好当第二路。
- DCMI 24Pin 口**不接**视觉模块（MaixCAM/K230 不是裸 DVP 摄像头）。

## 6. SWD 烧录/调试口

| SWD（`53261-0471`，4P） | MC02 | STLink V2 / DAPLink |
|---|---|---|
| 1 | 3V3 | 3.3V |
| 2 | `PA13` SWDIO | SWDIO |
| 3 | `PA14` SWCLK | SWCLK |
| 4 | GND | GND |

- 烧录时可只连 SWD 三根线（3V3 用板子自己的），但**调试时必须共地**。
- MC02 的 USB 口是 Type-C，走 USB-FS；板载 IMU 是 SPI 的 BMI088，不属于本次接线范围。

## 7. CAN 备用汇流（可选，先留端子）

### 7.1 拓扑

```text
MC02 CAN3 ──(H/L/GND)── PDB J2 ──┬── J3 ── X42 base  R/A/H=H, T/B/L=L
                                 ├── J4 ── X42 joint1
                                 └── J5 ── X42 joint2
[120Ω]                            [120Ω 只在 JP1 接通一次]
```

| 位置 | 终端电阻 | 说明 |
|---|---|---|
| MC02 板载 CAN3 | 已贴 120Ω（原理图 R2） | 母线这一端 |
| 分电板 JP1 | 120Ω，跳线接通 | 母线另一端，**只在这一端接** |
| 三个 X42 | 不接 | 中间节点不接终端 |

### 7.2 设置

| 项 | 值 |
|---|---|
| X42 `P_Serial` | `CAN1_MAP` |
| X42 地址 | 1 / 2 / 3 |
| 波特率 | 1 Mbps |
| MC02 | CAN3（`Pb12/Pb13`），收发器 5V 由可控 5V 供 |
| 线 | CAN_H/CAN_L 双绞，GND 随行 |

> CAN 只是**备用**：脉冲线不用拆，X42 支持脉冲与通讯混合控制。切换后可用 CAN 读位置/电流，比“到位输出”一根线更省引脚。

## 8. 上电自检清单（按顺序做，别跳）

| # | 动作 | 期望 | 不合格怎么办 |
|---|---|---|---|
| 1 | 断电，蜂鸣档量分电板 J1 正负 | 不响 | 查短路/反接 |
| 2 | 上电，量 TP24 对 TPGND | 24V ±5% | 查电源/保险丝 |
| 3 | 量 OUT1~OUT5 各自对 GND | 24V ±5% | 查对应保险丝 |
| 4 | 量 MC02 扩展口 #8 (3V3) 对 GND | 3.3V ±3% | 查 MC02 供电 |
| 5 | 程序拉高 `PC15` 后量 PWM 排口 5V | 5V ±5% | 查 5V_EN |
| 6 | **量三个 X42 的 COM 对 GND** | **3.3V，且绝不是 5V/24V** | 立刻断电重接 |
| 7 | 只接 base，发 1 kHz 脉冲 | 正转、不丢步 | 查 Stp/Dir/En/Hold |
| 8 | 翻转 Dir 再发 1 kHz | 反转 | 查 Dir 或改 Dir 有效电平 |
| 9 | 发“立即停止”/断 24V | 1 秒内停 | 查电源或固件 |
| 10 | STLink 连接 `PA13/PA14` | 识别到 H723 | 查 SWD 接线/BOOT0 |
| 11 | **拔一下三个 X42 的电源连接器** | 拔不动、无松动、不发热 | 是杜邦就换成端子或焊接（§3.5） |
| 12 | 满速跑 1 分钟后量 X42 `V+` 对 `Gnd` | ≥23.5V（掉压 <0.5V） | 掉压大 → 线太细/连接器接触不良 |

**一票否决项**：COM ≠ 3.3V、任何一路 24V 反接、X42 屏幕报 `Not Cal`/`Phase Error`。出现任意一条，停下查线，不要继续上电。

## 9. 待现场复核项（说明书没写死的地方）

| 项 | 现状 | 怎么复核 |
|---|---|---|
| PWM 排口第 2/3 路的丝印 | 附录标 `PE08/TIM1_CH4`，电源树标 `PE09`；`PE13` 确定是 TIM1_CH3 | 万用表量排口信号脚对 GND：哪个脚是 PWM 就是它。**接线前先量 5V 脚和 GND 脚位置**，别把信号插进 5V |
| LCD 口 #9 `PD10` | 原理图标注 GPIO，接 LCD 模块时被占用 | 不用 LCD 时可直接当 DIR1；要用 LCD 就换 `PD15`（扩展口 #9，本次空闲） |
| 扩展口 #11 `PD14` | 原 UART9_RX | 配成 GPIO 输出后不再做串口 |
| X42 光耦版/PLC 版 | 光耦版仅共阳；PLC 版共阳/共阴都行 | 下单时确认版本；两种都能按本表接 |
| X42 CAN 版本 | 复用口 CAN 需板载收发器 | 买“CAN 版本/集成通讯芯片版”，否则要插 ZDT_CAN 小板 |
| 5V 排口针距 | 说明书未写 2.54 还是 2.0 | 拿卡尺量，配对应端子 |
| 光耦驱动电流 | 手册没给 X42 输入电阻值 | 先用 1 kHz 试转；不转就在 Stp/Dir 对 3.3V 各加 1kΩ 上拉（把低电平灌电流抬到 ~2mA 以上） |

## 11. 扩展与替换（三轴之外）

| 场景 | 怎么接 | 注意 |
|---|---|---|
| **加第 4 轴** | STP 用剩下的 `PA2`(TIM2_CH3) 或 `PE9`；DIR 用 `PD15`(扩展口 #9)；COM/En 并到 3V3；供电另加一路 F6=3A | 没有第 5 路 PWM：再用轴就只能走 **CAN 控制**（每轴一个地址，只需 CAN_H/L/GND） |
| **换成 42 步进 0.9°** | 细分 16 时 4000 脉冲/圈，其余不变 | 改 `MotType` 为 0.9° 后要重新校准 |
| **改 CAN 主控** | 三轴 `P_Serial=CAN1_MAP`，脉冲线可全部不接 | CAN 版 X42 用 2×3P 口，`R/A/H=H`、`T/B/L=L` |
| **视觉改独立降压** | 分电板 OUT5 → 24V→5V 模块 → 视觉 | 不要与 MC02 5V 并接 |
| **要硬线急停** | 把一个轴的 `En` 改接 GPIO（如 `PD15`），`En` 参数设 `L` | 会牺牲一个 DIR/备用引脚；三轴急停建议直接断 24V 主开关 |

## 12. 与旧方案的差异（避免拿 F103 的记忆接错）
| 旧（F103 + TB6612） | 新（H723 + X42） |
|---|---|
| PWM + 方向电平驱动 TB6612 | 脉冲频率 + 方向电平驱动 X42（脉冲数=角度） |
| 编码器接 TIM 编码器模式 | X42 内部闭环，**不用外接编码器** |
| 5V 逻辑 | 3.3V 逻辑 + 共阳光耦（COM 必须 3.3V） |
| 12V 单电源 | 24V 分电，三轴独立保险 |
| 蓝牙 SPP 控制 | USB/串口/CAN，后续可上视觉 |
